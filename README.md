# 🎬 Netflix Content Dashboard

## 📌 Project Overview

This project analyzes Netflix movies and TV shows using Power BI.

---

## 🎯 Objectives

- Analyze Netflix content.
- Compare movies and TV shows.
- Identify top genres.
- Analyze ratings and popularity.
- Study content growth.

---

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Excel

---

## 📂 Dataset

- titles.csv
- credits.csv

---

## 📊 Dashboard Pages

### Executive Overview

- Total titles
- Average TMDB rating
- IMDb votes
- Top genres
- Content growth
- Movies vs TV shows

### Movie Analysis

- Average runtime by genre
- Rating distribution
- Age certification analysis
- Most popular movies

---

## 📈 Key Insights

- Total titles: 6000
- Average TMDB rating: 6.47
- Movies contribute 64% of the total content.
- TV shows contribute 36% of the total content.
- Average runtime: 76.89 minutes.
